Esta web es un proyecto personal, sin publicidad ni fines comerciales, y está hecha para no recoger datos de quien la visita.

## Responsable

Econplebs, web personal sin fines comerciales. Contacto: {{correo_contacto}}

## Qué datos se recogen

Ninguno a través de la web: no hay formularios, ni comentarios, ni boletín por correo, ni herramientas de analítica o de publicidad.

Si escribes al correo de contacto, tu mensaje se usa únicamente para responderte y se borra cuando ya no hace falta para atender la consulta. La base legal es tu consentimiento, que das al escribir.

## Registros del alojamiento

Como cualquier servidor, el que aloja esta web puede anotar automáticamente datos técnicos de cada visita (dirección IP, fecha y página pedida) para mantenerla segura y en funcionamiento. Esos registros no se usan para nada más ni se cruzan con otros datos.

## Cookies

Esta web no usa cookies. Las tipografías y las imágenes se sirven desde la propia web, sin llamadas a servidores de terceros. Los enlaces a otras webs (por ejemplo, las fichas de las fotos) solo te llevan allí si los pulsas.

Para seguir las novedades por RSS no hace falta dar ningún dato: tu lector consulta la web de vez en cuando, como cualquier visita.

## Tus derechos

Si has escrito, puedes pedir el acceso, la rectificación, la supresión, la oposición, la limitación o la portabilidad de tus datos escribiendo a la dirección de contacto. Si crees que no se han atendido bien, puedes reclamar ante la Agencia Española de Protección de Datos ([aepd.es](https://www.aepd.es)).
